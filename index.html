02.1 · fond d'écran audio-réactif

Woofer

Un fond d'écran Wayland qui réagit à la musique : les basses poussent l'image, chaque kick la fait vibrer.

Woofer lit le son directement dans PipeWire, calcule le rendu sur le GPU avec wgpu et se place sous les fenêtres grâce à wlr-layer-shell. Treize préréglages, du cône de haut-parleur au verre brisé, se changent à chaud avec woofer ctl ; --idle-fps 0 arrête le rendu dans le silence.

02.3 · son et image

equation sound lab

Des équations qu'on entend. On écrit y = f(x), un point parcourt la courbe et sa hauteur devient la hauteur du son.

La règle : f = 130,81 Hz × 2y. y = 0 donne un do3, +1 monte d'une octave. La courbe se trace en direct sous sa formule, typographiée par MathJax, et le lab exporte la vidéo avec ffmpeg.

03.1 · CLI Linux, macOS, Windows

c2pa-strip

Retire les Content Credentials (C2PA) des JPEG, PNG et WebP sans réencoder un seul pixel.

Le manifeste est rangé dans une boîte JUMBF. L'outil analyse le conteneur propre à chaque format et ne retire que le magasin C2PA : en JPEG, ses segments APP11, en gardant EXIF et ICC. À chaque push, la CI signe des images avec l'outil officiel c2patool, les nettoie et vérifie que le fichier est identique à l'original non signé.

$ c2pa-strip check photo.png
C2PA   photo.png  manifest store 100973 bytes, 1 manifest(s)
$ c2pa-strip remove photo.png
fixed  photo.png -> photo.clean.png  (219942 -> 118969 bytes)
$ c2patool photo.clean.png
Error: No claim found
$ cmp photo.clean.png original-before-signing.png && echo identical
identical

04.2 · console Docker Swarm

Phoenix Protocol

Trois managers Debian, des stacks réparties sur plusieurs machines : Phoenix donne une vue claire de ce que fait le cluster.

Il observe nœuds, services, stacks, tâches et réplicas. Un watchdog sur chaque manager journalise les transitions et les erreurs d'API. Le navigateur ne lit qu'un instantané JSON, jamais le socket Docker, qui reste derrière un proxy sur le réseau overlay interne. Le tout se déploie en mode global sur les managers éligibles.

05.1 · infrastructure as code

debian-rebuild

Un serveur Debian 13 durci, créé et configuré entièrement par script sous KVM/libvirt, puis vérifié par 22 tests.

Accès par clé SSH uniquement, root refusé, sudo toujours avec mot de passe. Pare-feu nftables en liste blanche, fail2ban, modules noyau inutiles bloqués, auditd sur les comptes, sudo, SSH et le pare-feu, mises à jour de sécurité automatiques. Lynis note le durcissement à 84/100, contre 67 pour la même VM avant.
